# Student Task Manager

A simple **Student Task Manager** built using HTML, CSS, and JavaScript. It helps students add, manage, and track their daily academic tasks.

## Features

* Add new tasks
* Mark tasks as completed
* Delete tasks
* Set task priority
* Add due dates
* Simple and responsive user interface
* Tasks are managed using JavaScript

## Technologies Used

* HTML5
* CSS3
* JavaScript

## Project Structure

```text
student-task-manager/
│
├── index.html
├── style.css
├── script.js
└── README.md
```

## How to Run

1. Download or clone the project.
2. Open the project folder.
3. Open `index.html` in any modern web browser.
4. Start adding and managing your tasks.

## Purpose

This project was created as a simple student task management application to practice fundamental **HTML, CSS, and JavaScript** concepts.
